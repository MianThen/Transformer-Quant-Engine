# MC-GATE-VALIDATION 结项声明

> 日期：2026-11-03　合同版本：**v1.5.0**
> 结论：**实验可以结束**——八条假设全部有判定，判据实现经 34 项 AC 验证，
> 全网格可复现（同二进制重跑逐字节一致）。剩余 6 项 AC 已逐条定处置（见 §三）。

---

## 一、结论汇总

| 假设 | 判定 | 关键数字 |
|---|---|---|
| **H0-OCN** | `T=4` 被 OCN 分区退化限制 | abstain **55.0 / 61.5 / 70.5%**（rho=0/0.3/0.7），远超合同原估 15–35% |
| **H1a** | 门控守住名义 FPR | 27 个 null 格 **max 4.64%**、中位 1.35%（判据 6.5%） |
| **H1b** | `T_eff` 被噪声底压低 | 实测 **3.30–3.35**（T=100, rho=0.3） |
| **H2** | 等 FPR 下的效率 | `Δ_stat` = **+13.1pp**、`Δ_ocn` = **−17.2pp**、`Δ_total` = **−4.1pp**（T=4） |
| **H3** | 假阳性差随 T 单调不减 | Δ = **83.2 → 94.3 → 96.1pp**（T=4/20/100） |
| **H4** | 实测门槛 = 解析门槛 | 9 个 S 点全部 `\|gap\| ≤ 0.036`（容差 0.10） |
| **H5** | 门控更少把诱饵当真 | DEC 块：GATE **38.6%** vs B0 **100%** / B1 **89.8%** |
| **H6** | 跨族重试击穿门控 | K=1 **0.90%** → K=10 **16.1%**（放大 17.9×；合同原预测 >40%） |

**最重要的单条**：`T=4` 的损失**主要来自 OCN 弃权（−17.2pp）**，统计层反而赚 +13.1pp。
§5.4 那句"不得把缺陷算到 DSR 头上"现在有硬证据。

## 二、可复现性

| 项 | 状态 |
|---|---|
| 同二进制重跑 | **逐字节一致**（aggregates 与 decisions 均实测相同） |
| 全网格重跑 | 28 分钟单核；`./mc_gate_full --out <dir>` |

## 三、剩余 6 项 AC 的处置

| AC | 处置 | 理由 |
|---|---|---|
| **AC-08** | **✗ 已跑并失败** | `Σz²=283.6 > 251.7`，偏差集中在 garch（+0.07～+0.16 SR）。根因是 `SR̂=μ̂/ŝ` 的有限样本正偏被波动聚集放大，**不是实现 bug**。按 §3.5 标 `dgp_global_shift`。详见 `docs/mc_gate_ac08_truth_recovery.md` |
| **AC-12** | **✗ 明确不做** | "5 布尔全真 ⇒ candidate_selected == winner_frozen" 需要生产侧 `policy_family_governance` 的逻辑作为参照，本仓库没有该实现 |
| **AC-14** | **◐ 部分完成** | C21 在 1 个真实矩阵上完成 Python 独立复算；扩到 120 个需全网格驱动输出 replay，属驱动改动 + 28 分钟重跑 |
| **AC-28** | **✗ 明确不做** | 同上：`G_full` 与**生产侧**门控的 `artifact_hash` 比对需要生产代码。四个消融变体之间的相对关系已实测（见 ABL 表） |
| **AC-30** | **✗ 明确不做** | `OCNP` pilot 要求**先于**主 run 执行，顺序不可回溯。替代证据：C28 的 18 格 OCN 测量（abstain 率与 Δ_ocn 分解） |
| **AC-39** | **◐ 部分完成** | C23 已验证 1 个数据集的前 8 个 double 位级一致；12 个数据集需要 replay 全集 |

**净结果：✓ 34 / ◐ 2 / ✗ 4（共 40 项）**。四项 ✗ 中两项是"明确不做（缺生产侧参照）"、
一项是"顺序不可回溯"、一项是"已跑并失败（有独立解释）"。

## 四、构建期发现的真实缺口（都已修）

| # | 缺口 | 性质 |
|---|---|---|
| 1 | `T`/`N` 转置（F7） | 实现缺陷，修好后 F1/F3 两条警报撤回 |
| 2 | `kSigmaP` 手写字面量（F8） | 与 `0.10/kScale` 差 9.7e-6 |
| 3 | `κ` 取自 `ret` 而非 `assign` 子流 | 违反 §3.6.1 约束 4 |
| 4 | `variant` 未接入驱动 → **ABL 消融从未执行** | 字段在、值为占位 |
| 5 | `returns_sha256` 一律写 0 → AC-18 是空断言 | 同上 |
| 6 | 输出路径写死 → 全网格原始记录被后续运行覆盖 | 已改 `--out` |

**规律**：第 4、5 条是同一类——**字段填了占位值比字段没填更危险**，因为验收器会通过。

## 五、模型能力边界（本实验第二项产出）

32 个卡片文件（C06R 为 C06 重发）全部施工完成；**卡作者缺陷 29 次，模型真实缺陷 1 次**
（SHA-256 padding 的循环不变量）。作业规范已固化为 DSH 技能 `local-model-card-ops`。

## 六、已知局限（不影响定性结论）

1. **garch 的功率数字偏乐观约 10%**（AC-08 的偏差所致）；
2. **`D=202` 未兑现**：驱动未实现 `calls_per_rep`，实际独立面板 **193**，
   差额 9 = `RET` 的 `K=10` 辅助面板；
3. **ABL 只在 `T=100,N=266,rho=0.3` 上做过**（40 格），换 T/N 的等价性未验证；
4. **`cost_profile` 只实测 3/6 个 (T,N) 桶**。

## 七、一句话

> 门控守得住假阳性、对负 alpha 零误选、功率随信号单调上升；
> `T=4` 的劣势来自 OCN 弃权而非 DSR；跨族重试是真实风险但比合同预估小得多。
> 所有判据都可复现，所有预期值都已按实测修订进 v1.5.0。
